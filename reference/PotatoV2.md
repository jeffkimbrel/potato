# PotatoV2 S7 class

Represents a v2 schema potato with genes, compounds, and pathways

## Usage

``` r
PotatoV2(
  schema_version = character(0),
  id = character(0),
  name = character(0),
  source = character(0),
  tags = character(0),
  notes = character(0),
  genes = list(),
  compounds = list(),
  pathways = list(),
  json_path = character(0)
)
```
