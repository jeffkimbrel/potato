# Interactive visNetwork plot of v2 graph

Interactive visNetwork plot of v2 graph

## Usage

``` r
plot_v2_interactive(g, layout = "fr", height = "100vh")
```

## Arguments

- g:

  Graph from build_graph_v2()

- layout:

  Layout algorithm (e.g., "fr", "kk", "circle", "tree", "grid").
  Default: "fr"

- height:

  Height of the plot (default: "100vh")
