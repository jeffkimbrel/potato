# Create .hal file for kofam from potato KO list

Create .hal file for kofam from potato KO list

## Usage

``` r
create_kofam_hal(sack, potato_names = NULL)
```

## Arguments

- sack:

  PotatoSack object

- potato_names:

  Vector of potato names (NULL = all)

## Value

List with hal_path and modified sack
